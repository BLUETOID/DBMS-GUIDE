-- Advanced Analytical SQL & Relational Synthesis
SELECT 
    d.dept_name,
    s.student_name,
    ROUND(AVG(e.score), 2) AS cumulative_gpa,
    DENSE_RANK() OVER (
        PARTITION BY d.dept_id 
        ORDER BY AVG(e.score) DESC
    ) AS ranking
FROM students s
JOIN enrollments e ON s.student_id = e.student_id
JOIN departments d ON s.dept_id = d.dept_id
WHERE e.semester = 'Fall-2025'
GROUP BY d.dept_id, s.student_id
HAVING AVG(e.score) >= 8.5
ORDER BY d.dept_name ASC, ranking ASC;

Why Master Database Systems?

ACID Reliability

Database management systems guarantee zero data loss, strict transactional atomicity, and durable recovery even through sudden hardware failures.

High Concurrency & Scale

Learn how modern relational and distributed engines handle millions of simultaneous queries without collisions or lost updates using 2PL and MVCC.

Relational Synthesis

Formulate mathematically proven relation structures that eliminate update, deletion, and insertion anomalies using 3NF and Boyce-Codd Normal Form.

Industry Standard

SQL and database engineering form the foundational backbone for cloud architectures, data engineering, backend APIs, and enterprise software.
