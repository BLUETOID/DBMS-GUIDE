6.2 Filtering Grouped Aggregates with HAVING
IntermediateHAVING

WHERE filters base rows before grouping; HAVING filters aggregated groups after computation. Aggregate functions (e.g. AVG() > 80000) are invalid in WHERE and must go in HAVING.

7.1 Labeling Tiers with Searched CASE WHEN
IntermediateCASE WHEN

Evaluate boolean conditions sequentially: when a condition evaluates to TRUE, its corresponding THEN result is returned, falling back to ELSE.

SELECT first_name, last_name, salary,

11.3 Common Table Expressions (CTE with WITH)
AdvancedCTE (WITH)

CTEs modularize complex queries into temporary named result sets that can be referenced in the main query just like a table.

CTE: Pre-computed Dept Averagesdept_id → avg_sal
dept_namedept_avg
Engineering$88,333.33
Marketing$79,500.00
Sales$80,500.00
Output: Earners Above Dept AverageFiltered against CTE
first_namedept_namesalarydept_avg
AliceEngineering$95,000$88,333.33
EvanMarketing$91,000$79,500.00
SQL Query (TECHCORP DB) 
WITH DeptStats AS (
    SELECT dept_id, AVG(salary) AS avg_sal
    FROM employees
    WHERE dept_id IS NOT NULL
    GROUP BY dept_id
)
SELECT e.first_name, e.salary, d.dept_name, ROUND(ds.avg_sal, 2) AS dept_avg
FROM employees e
JOIN DeptStats ds ON e.dept_id = ds.dept_id
JOIN departments d ON e.dept_id = d.dept_id
WHERE e.salary > ds.avg_sal;

Module 12: Real-World Interview & Benchmark Challenges

SQLZoo, LeetCode, and FAANG technical interview benchmark queries with explanations and optimal solutions.

4 Challenges
Challenge 1: Find the Second Highest Salary (LeetCode #176)
Interview Classic

Problem Statement: Write an SQL query to report the second highest distinct salary from the employees table. If there is no second highest salary, return NULL.

SQL Query (TECHCORP DB) 
SELECT MAX(salary) AS SecondHighestSalary
FROM employees
WHERE salary < (SELECT MAX(salary) FROM employees);

Alternative with Window Functions: SELECT salary FROM (SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) as rnk FROM employees) WHERE rnk = 2 LIMIT 1;

Challenge 2: Department Top 3 Salaries (LeetCode #185)
Hard

Problem Statement: High earners in a company are employees whose salaries are in the top three unique salaries for their department.

SQL Query (TECHCORP DB) 
WITH RankedSalaries AS (
    SELECT 
        d.dept_name AS Department,
        e.first_name || ' ' || e.last_name AS Employee,
        e.salary AS Salary,
        DENSE_RANK() OVER (PARTITION BY e.dept_id ORDER BY e.salary DESC) AS rnk
    FROM employees e
    JOIN departments d ON e.dept_id = d.dept_id
)
SELECT Department, Employee, Salary
FROM RankedSalaries
WHERE rnk <= 3
ORDER BY Department ASC, Salary DESC;
Challenge 3: Customers Who Never Order (LeetCode #183)
Easy

Problem Statement: Find all customers who have never placed an order in the retail store.

SQL Query (RETAIL DB) 
SELECT c.name AS Customers
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
Challenge 4: Find Highest-Grossing Director per Era
Intermediate

Problem Statement: Rank directors by their total domestic box office earnings for movies released after 2000.

SQL Query (MOVIES DB) 
SELECT 
    m.director,
    COUNT(m.id) AS total_films,
    SUM(b.domestic_sales) AS total_domestic_gross
FROM movies m
JOIN box_office b ON m.id = b.movie_id
WHERE m.year >= 2000
GROUP BY m.director
ORDER BY total_domestic_gross DESC;
